FanPlusFollow PWA package

Upload every file in this folder to the ROOT of the GitHub Pages repository, replacing the existing index.html only after keeping a backup.

Included:
- index.html (existing app, with local image paths, PWA metadata, and service-worker registration)
- manifest.webmanifest
- sw.js
- all eight PNGs supplied by you
- icon-192.png and icon-512.png generated by resizing your existing brand_logo.png

Offline behavior:
- The service worker precaches the app HTML, manifest, all supplied PNG artwork/backgrounds, and app icons.
- The existing app uses Tailwind from https://cdn.tailwindcss.com and Inter from Google Fonts. The service worker attempts to cache these online dependencies during installation, but their availability offline is best-effort. The PNGs themselves are bundled locally and do not need internet access.
- Video title/description generation is performed locally from the uploaded filename; no video is uploaded by this page.
- GitHub Pages must be opened over HTTPS. After the first online visit, open the site again once so the service worker can finish caching, then use the browser's Install app / Add to Home screen option.
